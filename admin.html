Cursos y alumnos

Primero elige el curso. Luego puedes agregar varios alumnos a la vez, crear sus cuentas o descargar el boletín. Más abajo está la lista de alumnos de ese curso.

Curso actual —

Elige un curso para empezar.

Agregar varios alumnos a la vez

Un alumno por línea: nombre, apellido. La matrícula se crea sola.
Si quieres poner tú la matrícula: matrícula, nombre, apellido

Cuentas para que los alumnos entren

Crea de una vez el usuario de cada alumno que aún no tenga cuenta. El alumno entra con su primer nombre en minúscula más los últimos 4 dígitos de la matrícula (ejemplo: Juan con 26-0001 entra como juan0001).
Si dejas la contraseña vacía, esa misma clave es su contraseña inicial.

Boletín de notas

El PDF y el Excel se generan para el curso actual (el de la barra de arriba). Incluye todas las materias del curso.

Alumnos del curso

Agrega un alumno, cambia su orden en la lista, muévelo a otro curso o bórralo.

Materias y profesores

Estas fichas son de toda la escuela, no de un solo curso. Aquí puedes crear maestros (con su usuario y contraseña), ordenar sus fichas, quitarles las materias o eliminarlos. Abre un grado para ver las secciones A, B, C y D, y marca las materias que le corresponden. Al marcar o desmarcar se guarda solo. Toca el nombre del maestro para ver un resumen de lo que imparte.

Agregar maestro

Crea el usuario y la contraseña con los que el maestro va a entrar. Si escribes un usuario sin @, se le agrega @profesores.liceo.do (ejemplo: ana queda como ana@profesores.liceo.do).
El maestro debe iniciar sesión con ese correo completo (por ejemplo ana@profesores.liceo.do), no solo con el usuario corto. La contraseña debe tener al menos 6 caracteres.

Agregar varios

Un maestro por línea: nombre, apellido, correo, contraseña. Si el correo no tiene @, se le agrega @profesores.liceo.do. Ellos entran con el correo completo que quede guardado.
